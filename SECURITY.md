# Security policy

Please use GitHub's **Report a vulnerability** flow for this repository when available. If it is unavailable, ask the maintainers for a private reporting channel through the organization contact. Do not post credentials, exploitable details, wallet data or user data in a public issue or pull request.

Include the affected revision, a minimal reproduction with disposable data, and the expected impact. Maintainers will coordinate validation and disclosure. This repository is not a place to submit bitcoin signing or recovery material.
